# 🌐 Meu Portfólio Web

Este é meu portfólio pessoal desenvolvido com **React**, **TypeScript** e **Motion**, com o objetivo de apresentar meus principais projetos, habilidades e experiências como desenvolvedor full-stack.

## ✨ Tecnologias Utilizadas

- **React** – Biblioteca principal para construção da UI
- **TypeScript** – Tipagem estática para maior segurança e clareza no desenvolvimento
- **Motion** – Animações fluidas e interações modernas
- **TailwindCSS** – Estilização rápida e responsiva
- **Vite** – Bundler leve e rápido
- **Vercel** – Hospedagem do portfólio
